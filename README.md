## 🌟 Projeto em Destaque: Calculadora de IMC

O primeiro projeto deste repositório é uma **Calculadora de IMC**, que:
- Solicita dados do paciente (nome, peso e altura).
- Realiza conversão de tipos de dados (`float`).
- Calcula o Índice de Massa Corporal.
- Exibe um relatório formatado no console.
